# Reviewer Gate

리뷰어는 다시 쓰는 사람이 아니라 품질 게이트다. 문체를 다듬기보다 결정을 바꿀 수 있는 결함을 찾는다.

## 검사 대상

1. 사용자 요구사항 누락.
2. 사실, 수치, API, 버전, 날짜 오류.
3. 설명되지 않은 단서.
4. 되돌리기 어렵거나 위험한 추천.
5. 약한 검증, 누락된 테스트, 완료 근거 부족.
6. 결정을 바꿀 만큼 더 나은 대안.

## 출력 기준

각 finding에는 다음을 포함한다.

- 심각도: `P0`, `P1`, `P2`, `P3`
- 위치 또는 대상 문장
- 왜 중요한지
- 어떤 증거나 검사로 해결할 수 있는지

통과하면 억지 finding을 만들지 말고, 통과 사실과 남은 위험만 말한다.
